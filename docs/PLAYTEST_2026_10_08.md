# FIRETEAM - October 8 Gameplay / Regression QA

This patch is a first pass for **Cabin Fever and BLACKLUNG**. Do not
reintroduce JUNK_FLEA to Quick Play; it remains on disk for future work.

## Changes

1. Quick Play filters JUNKFLEA / JUNK_FLEA out of discovered DATs. Other
   imported maps remain available; no commercial assets were changed.
2. Round state packets now carry a bool for whether the round is **actively
   fighting**. Client and server track combat-only elapsed seconds so
   Bottomless Mag, One Hit, God Mode, and Zombie Wallhack countdowns **pause
   during preparation, round intermissions and game over**. Respawn's
   three seconds of damage immunity use separate REAL server time.
3. Bottomless Mag can fire an empty 0/0 ranged weapon without using ammo,
   including when swapping to an empty second weapon. It does NOT fabricate
   reserve ammunition. Ammo Resupply adds real reserves; at Bottomless expiry
   an empty ACTIVE magazine is filled from those reserves (if available).
   A finished/cancelled reload explicitly returns the weapon to idle, instead
   of leaving an imported reload animation cycling.
4. The launcher writes `cabin_spawn_guard=1` only when Cabin Fever is
   selected. The server reads the compiled DAT GameStartPoint00 and guards a
   **temporary** 720-unit flat radius about that authored origin. It only
   filters nearby named Spawner anchors while there are other authored
   candidates. The guard ends at:
   - Difficulty 0-1: round 20
   - Difficulty 2-3: round 14
   - Difficulty 4-5: round 8
   - Difficulty 6-7: round 5
   - Difficulty 8-9: round 2
   - Difficulty 10: round 1
   This is deliberately approximate and does not change geometry, player
   starts, or Zombie Wallhack. An emergency fallback prevents a broken map
   from getting stuck if zero exterior anchors remain.
5. The server prints one `Fireteam DAT anchor N/M:` line for each actual
   authored Spawner/ObjectSpawnPoint/PatrolNode in a loaded DAT, with its
   name, world XYZ and tentative near-start classification. This lets us
   map Cabin Fever spawns without an original LTA/LTC file.
6. `+FTLightGroupOverrides 0` skips runtime light-group modulation while
   preserving authored baked lightmaps. Compare a short screenshot of the
   broken lamps with overrides ON (default) and OFF. If the jagged
   transparent/white pieces persist, the next target is the lamp
   sprite/DTX/RenderStyle asset rather than global brightness.

## Build and A/B checklist

    git pull --ff-only
    build.cmd

- Cabin Fever difficulty 5 round 1: 15 second prep, no near-start surprise.
- Cabin Fever difficulty 5 round 8+: near-start surprises possible again.
- Cabin Fever difficulty 10 round 1: near-start surprises possible.
- Check early log `Fireteam DAT anchor` for exact map object positions.
- Collect a 30s buff right as a round ends; the HUD should freeze its
  remaining seconds until the next round begins.
- Bottomless with 0/0 ammo: gun still fires, reserve remains zero.
- Bottomless + Ammo Resupply at 0/0: continued firing; when it expires,
  active weapon receives ammo drawn ONLY from the resupplied reserve.
- No stuck reload animation after Bottomless cancellation or expiration.
- Start Cabin Fever once with `+FTLightGroupOverrides 0` and once with
  `+FTLightGroupOverrides 1`, screenshot the same wall lamps.
